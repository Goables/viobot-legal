# Viobot Privacy Policy

Effective Date: 6/23/2026

Viobot is a Discord moderation and utility bot designed to help Discord server staff manage moderation records, reminders, tickets, server configuration, aliases, server variables, logging, premium features, beta features, automated safety features, and related server safety tools.

This Privacy Policy explains what information Viobot may collect, how that information is used, how long it may be kept, and how users can request access to or deletion of information stored by Viobot.

## 1. Information Viobot May Collect

Viobot may store limited Discord-related information needed to provide its features. This may include:

* Discord user IDs
* Discord server/guild IDs
* Discord channel IDs
* Discord role IDs
* Discord thread IDs, thread names, parent channel IDs, and thread owner IDs when available
* Message IDs related to bot logs, moderation records, ticket records, or bot workflows
* Moderator IDs associated with moderation actions
* Moderation action records, such as warnings, mutes, suspicious-account mutes, voice mutes, bans, unbans, nickname changes, role changes, and related reasons
* Command options or command metadata when needed for moderation records, such as whether a moderation command skipped a direct message or omitted appeal-related text
* Account safety information used by configured safety features, such as account creation time, join time, account age checks, and related staff alerts
* Mute and voice-mute role restoration data
* Saved role snapshots used to restore roles after a member rejoins or is unmuted
* Reminder messages and expiration times
* Scheduled announcement content, destination channel IDs, creator IDs, scheduled send times, and related timestamps
* Server configuration settings
* Server variables, including variable names, variable values, updater information when stored, and timestamps
* Public aliases and private moderator aliases, including alias names, help text, access settings, raw alias content, parsed alias actions, owner or creator IDs, updater IDs, and timestamps
* Ticket-related metadata, such as ticket thread IDs, ticket category choices, custom Contact Us categories, and contact workflow data
* Papertrail or evidence links added by moderators
* Thread logging data, such as thread creation, archive, and unarchive events
* Timestamps related to bot actions
* Beta program records, such as beta server IDs, enabled beta feature flags, the user ID of the person who added or updated beta access, optional beta notes or reasons, and related timestamps
* Premium access records, such as Discord SKU IDs, entitlement-related access information, premium feature keys, access check results, and related timestamps
* Server-specific bot appearance data for enabled servers, such as custom Viobot server avatar images or processed image data, MIME type, updater user ID, and related timestamps
* Data created by premium or beta features, such as activity reports, custom Contact Us categories, scheduled announcements, server-specific bot appearance settings, or expanded alias data, if those features are enabled

Viobot may process message content, attachments, usernames, display names, role state, or other Discord-provided context when needed for configured moderation, logging, tickets, aliases, reminders, scam or spam detection, automated safety checks, or other bot features.

Viobot does not intentionally collect email addresses, phone numbers, payment card information, banking information, passwords, or Discord account credentials.

## 2. How Viobot Uses Information

Viobot uses stored information to provide bot functionality, including:

* Enforcing server rules
* Maintaining moderation history
* Restoring roles after mutes, voice mutes, suspicious-account mutes, or rejoins
* Logging moderation and server safety events
* Logging thread creation, archive, and unarchive events when logging is enabled
* Supporting moderator review, appeals, and accountability
* Sending reminders requested by users
* Sending scheduled announcements configured by authorized staff
* Managing server-specific bot configuration
* Managing aliases, private aliases, and server variables
* Inserting server variables into supported alias output
* Supporting ticket/contact workflows and custom Contact Us categories
* Preventing abuse, ban evasion, mute evasion, spam, scams, or other harmful behavior
* Applying configured automated safety actions, such as suspicious-account mutes for accounts under a configured age threshold
* Providing beta features to approved servers
* Verifying access to Viobot Plus or other premium features
* Enforcing free, beta, and premium feature limits
* Providing server-specific bot appearance features when enabled
* Generating moderation activity reports or other server-management reports when enabled
* Troubleshooting, securing, and maintaining Viobot services

Viobot does not sell user data.

## 3. Beta Program

Viobot may offer a beta program that allows selected servers to test new or experimental features before they are generally available.

If a server is added to the Viobot beta program, Viobot may store information needed to manage that access, including the server ID, enabled beta feature flags, the user ID of the person who added or updated the beta access, optional notes or reasons, and timestamps.

Beta features may change, be limited, be removed, or behave differently from stable public features. Beta features may use the same categories of server, user, moderation, configuration, ticket, alias, variable, reminder, logging, premium-related, and server appearance data described elsewhere in this Privacy Policy.

Viobot may also use beta status to change server-specific bot behavior, such as enabling beta-only commands, increasing feature limits, enabling custom Contact Us categories, enabling timed announcements, enabling automated safety features, or displaying beta-specific bot appearance settings in that server.

## 4. Viobot Plus and Premium Features

Viobot may offer optional paid features, including Viobot Plus. Premium features may include expanded limits, activity reports, timed announcements, custom Contact Us ticket categories, server-specific bot appearance settings, advanced moderation tools, or other server-management tools.

To determine whether a server or user has access to a premium feature, Viobot may process limited access-related information, including:

* Discord server IDs
* Discord user IDs when needed for command usage or access checks
* Discord SKU IDs
* Discord entitlement-related information
* Premium feature keys
* Access check results, such as whether access is available through Viobot Plus, beta access, bot-owner access, or another authorized source
* Timestamps related to access checks or cached premium status

Viobot uses this information only to provide, limit, verify, troubleshoot, and administer premium or beta features.

## 5. Payment Information

Viobot does not intentionally collect or store full payment card numbers, banking information, or other direct payment method details.

If Viobot Plus or another premium feature is purchased through Discord, payment processing, billing, cancellations, refunds, taxes, and related payment information are handled by Discord according to Discord's own terms and policies.

Viobot may receive or access limited Discord-provided information showing whether a server or user has access to a premium feature, but Viobot does not receive full payment method details.

## 6. Premium and Beta Feature Data

Some premium or beta features may create or use additional data. Depending on which features are enabled, this may include:

* Moderation activity reports generated from existing moderation records
* Higher alias limits or expanded alias data
* Custom Contact Us ticket categories
* Timed announcement records
* Server-specific Viobot avatar or appearance settings
* Premium or beta access status shown through tools such as Plus/Beta command listings

This data is used to provide the enabled feature, support server moderation, troubleshoot issues, prevent abuse, and maintain Viobot's services.

If beta access or premium access is removed, Viobot may stop allowing new use of premium-only or beta-only features. Some existing data created while a feature was enabled may remain stored unless deleted through normal retention, server configuration, moderation cleanup, feature reset, or a valid deletion request.

For example, removing premium access may prevent creating additional premium-only resources, but may not automatically delete existing moderation records, aliases, custom category settings, server-specific avatar settings, or activity reports.

## 7. Automated Moderation and Safety Records

Viobot may create or store records related to automated moderation and safety features when those features are configured or enabled by server staff.

This may include account-age alerts, suspicious-account mute records, spam or scam detection records, deleted-message references, saved role snapshots, automated moderator identifiers such as AutoMod, reasons for automated actions, and log references.

Automated safety records may be visible to authorized server staff through configured logging, violation, ticket, or staff channels. Server staff are responsible for reviewing automated actions and correcting them when appropriate.

## 8. Moderation Records

Because Viobot is a moderation bot, some records may be retained when necessary for server safety, rule enforcement, abuse prevention, dispute resolution, or moderation accountability.

This may include records of warnings, mutes, suspicious-account mutes, voice mutes, bans, unbans, role changes, nickname changes, moderator notes, papertrail evidence, premium-generated moderation reports, automated safety records, and related log references.

A user may request deletion or review of their data, but some moderation records may be retained if deletion would interfere with legitimate moderation, safety, appeal, or abuse-prevention needs. Where full deletion is not appropriate, Viobot administrators may choose to minimize, restrict, or anonymize records when feasible.

## 9. Data Sharing

Viobot does not sell or rent stored data.

Stored information may be visible to authorized server staff, depending on the server's configuration and Discord permissions. For example, moderation logs may be posted in staff-only channels, ticket information may be visible to moderators, thread event logs may be visible in logging channels, automated safety alerts may be visible to staff, and activity reports may be visible to authorized staff.

Data may also be processed by Discord because Viobot operates through Discord's platform and APIs.

If premium features are purchased or managed through Discord, Discord may process payment, subscription, billing, entitlement, and account-related information according to Discord's own terms and policies.

Viobot data is not shared with third parties except where necessary to operate the bot, comply with legal obligations, respond to security issues, verify premium access, or protect users and servers from abuse.

## 10. Data Retention

Viobot keeps data only as long as reasonably necessary for its features and moderation purposes.

Different types of data may be kept for different periods:

* Reminders are normally deleted after they are sent or expire.
* Temporary mute data may be deleted after the mute ends and roles are restored.
* Role restoration snapshots may be kept while needed for mute, voice mute, suspicious-account mute, or rejoin restoration workflows.
* Server configuration is kept while Viobot remains configured for a server.
* Server variables are kept until deleted by authorized staff or until removed through server configuration cleanup.
* Alias data is kept until deleted by an authorized moderator or alias owner.
* Scheduled announcements may be deleted after they are sent or canceled, unless retained for troubleshooting or moderation accountability.
* Ticket metadata and custom Contact Us category settings may be kept while the ticket system or related configuration remains active.
* Server-specific custom avatar data may be kept until it is replaced, reset, removed through cleanup, or otherwise deleted according to applicable retention rules.
* Beta access records may be kept while a server participates in the beta program or while needed for troubleshooting, security, or administrative records.
* Premium access records may be kept while needed to verify access, troubleshoot premium features, enforce limits, prevent abuse, or maintain administrative records.
* Premium-created data, such as reports, custom category settings, server-specific appearance settings, or expanded feature data, may be kept according to the retention rules for that feature.
* Moderation and automated safety records may be retained for server safety, accountability, appeals, and abuse prevention.
* Papertrail or evidence references may be retained as part of moderation records.

Server owners or authorized administrators may request removal of server configuration data if Viobot is removed from a server.

## 12. Server Owner and Moderator Controls

Server owners and authorized moderators are responsible for how they configure and use Viobot in their servers.

This includes deciding which channels receive logs, which roles can use moderation commands, how tickets are handled, whether aliases or server variables are used, whether automated safety features are enabled, whether certain records should be retained for moderation purposes, whether server-specific appearance features are used, and whether beta or premium features should be used in the server.

Server owners and authorized moderators are also responsible for ensuring that their use of Viobot complies with applicable Discord rules, server rules, and legal obligations.

## 13. Security

Viobot stores data in a database controlled by the bot operator. Reasonable efforts are made to limit access to stored data and prevent unauthorized access.

However, no system can be guaranteed to be completely secure. Users should avoid sending sensitive personal information through bot commands, tickets, aliases, variables, reminders, announcements, reports, or moderation notes unless necessary.

## 14. Children

Viobot is intended for use within Discord servers and is not directed at children under the minimum age required to use Discord.
